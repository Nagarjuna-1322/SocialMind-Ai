# SocialMind AI demo script

## Story

“Most AI content tools forget your brand's history. SocialMind remembers what your audience responded to and uses that memory to improve the next recommendation.”

## 90-second flow

1. **Dashboard** — TechNova has 80 analyzed posts, 924K reach, and a 6.3% average engagement rate. AI Tools leads the topic ranking.
2. **AI strategy** — Ask “What should we post next week?” The answer favors the strongest topics, formats, and posting windows rather than generic ideas.
3. **Why** — Expand Memory used. Point to source post IDs and the explicit RETAIN → RECALL → REFLECT lifecycle.
4. **Add learning** — In Content history, add `P101`, a practical Generative AI tutorial with strong reach and audience requests for examples.
5. **Ask again** — Run the same question. With Hindsight connected, the new retained outcome is available to the next recall/reflect pass.
6. **Close** — The value is not “AI can write a caption.” It is that SocialMind can remember what worked for this brand and keep making the next decision more specific.

## Live setup note

For a real memory demo, configure `HINDSIGHT_BASE_URL`, `HINDSIGHT_API_KEY`, and `HINDSIGHT_BANK_ID` on the server before the recording. If the service is not configured, the interface intentionally shows the unavailable state rather than pretending local database rows are Hindsight memories.
